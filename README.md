# office-joke

One entry for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty.

`main.py` writes a single one-line joke about office life to `entry.txt` — the
meeting that could have been an email, except the email has other plans.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Deterministic, no network, no model calls. The joke is 83 characters, one line.
